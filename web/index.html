      Drawing checks

      Select a line to select what it is about. Checks never block drawing and change nothing.

        Drawing with the keyboard
        • Arrow keys: move the focus along the bonds; Home: first atom; Page Down / Page Up: next or previous structure.
        • Enter: grow a single bond from the focused atom; Shift+Enter: a double bond. On an empty canvas Enter places a carbon.
        • A letter sets the element (C N O S P F H B I, Shift+C chlorine, Shift+B bromine); 1 2 3 set the order of the bond just walked; + and − change the charge.
        • With a selection: Alt+Arrow moves it by 0.1 bond length, Alt+Shift+Arrow by 1; Alt+[ and Alt+] turn it by 15° (repeated presses are one undo step). Shift+Arrow adds the atom the focus walks to. M: click an empty spot to bring the selection there.
        • Shift+D (when pathway.derive is on): derive a transformation product: copy the focused or selected structure with its atom maps, with an arrow to the copy; the copy is selected, so the next edit applies to it.
        • Space: select the focused atom; Delete: remove it; Escape: leave the focus. Tab leaves the canvas.
