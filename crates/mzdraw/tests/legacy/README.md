# Files of an earlier name

Synthetic files written as a program of an earlier name wrote them, under the slug `zzzzzz` (as long as the current slug, so the byte offsets of the PDF hold): a document, a settings file with `export.default`, an SVG, a PNG and a PDF that carry the same small drawing (C=O). The unit tests of `crates/mzdraw/src/brand.rs` read them with `LEGACY_IDS = ["zzzzzz"]` (a seam of `cfg(test)`) and check that every one opens, and that what is written back carries the current name.

They are not regenerated by a test. To make them again, build the `replay` example, write the drawing with `out` set to `mzdraw`, `svg` and `pdf`, and put `zzzzzz` where the current slug is (the format id, the SVG `metadata` id, the two PDF attachment names); the PNG is a 1x1 image with an `iTXt` chunk whose keyword is `zzzzzz`.
