# Drawing checks `std/1`, stereo family, built

(`crates/mzdraw/src/conform.rs`; section "Drawing checks" of docs/mzdraw.md): `conform::report(&Document)` gives findings `{key, grade, atoms, bonds, objects}`; the JSON `{"format":"std/1","checks":[...]}` is written by hand, ordered by key then smallest id, ids ascending, empty lists left out. One door for every surface: `Editor::save("std")` = the replay request `"out":"std"` (the CLI twin; deterministic bytes, parity wasm == native in `tests/parity.mjs`); an unknown `out` is the keyed error `error.draw2.request`. The report is read-only and no undo step. The page has a closed panel "Drawing checks": the bridge hands over `state().std` (`{none, lines: [{key, grade, n}]}`, recomputed after each change; `none` is decided in Rust and the page only shows its text), a line selects what its findings are about (`select_check(key)`: the selection is view state, not a log operation, so it has no CLI twin). Screenshots of the panel at deviceScaleFactor 2: `docs/shots/std-light.png`, `std-dark.png`, `std-tablet.png`. Not built: five further stereo checks named by the coordinator, `std.stereo.fischerCross`, `std.stereo.reentrant`, `std.stereo.ringBond`, `std.stereo.hiddenH` and `std.stereo.relLabel` (this slice builds 9 of those 14; they are for a follow-up prompt and are not defined in the study yet); geometry, label and export checks (`std.geom.*`, `std.label.*`, `std.export.*`), annotation and contrast checks, CIP labels, any automatic fix.
