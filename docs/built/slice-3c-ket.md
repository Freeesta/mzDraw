# Slice 3c, built (KET)

the JSON format of Ketcher and Indigo, written and read from its published schema (`crates/mzdraw/src/ket.rs`, no code of theirs). Out (`save("ket")`): one molecule node with every atom (abbreviations expanded, R groups as `rg-label` atoms with `rg-n`, charge, isotope, radical, an explicit hydrogen count as `implicitHCount`), wedges as bond `stereo` 1 / 6 / 4 from the narrow end, arrows (`open-angle`), plus signs and texts as root nodes; the text of an arrow is a text node above its middle (KET has none on an arrow). In: every molecule of the file goes through the same door as a molfile, so aromatic bonds are kekulised and R groups, atom lists and other query atoms, query bonds and S-groups are treated and listed as there; arrows, plus signs and texts (rich-text content or a plain string; one document text per line) keep their place next to the atoms; shapes, images, multi-tailed arrows and R-group definitions are counted and said (`draw2.import.other`). Not read: `implicitHCount` (the valence rules decide), atom aliases, the stereo labels of enhanced stereo. The labels `D` and `T` are read as query atoms.
