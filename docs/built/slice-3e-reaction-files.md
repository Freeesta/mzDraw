# Slice 3e, built (reaction files)

RXN V2000 and V3000 and RD files are read (`crates/mzdraw/src/rxn.rs`); RXN V2000 is written. A reaction file holds molecules and their roles, not a picture: read, the reactants are set on one line left of an arrow and the products right of it, with plus signs between them, and the agents (the third count of V2000, the `AGENT` block of V3000) above the arrow; every molecule goes through the same door as a molfile, so its R groups and out-of-scope parts are treated and listed the same way. The records of an RD file (`$RFMT` reactions, `$MFMT` molecules; 64 at a time, the rest is said) are set one under the other; their data (`$DTYPE` / `$DATUM`) is not read. Written (`save("rxn")`): the drawing must hold exactly one arrow (else `error.draw2.rxnArrow`, said under the Save buttons); a structure is a reactant, a product or an agent by where its middle stands along the arrow (before the tail, past the head, alongside), in order along the arrow, so a slanted arrow works; agents are written as a third count, an extension several programs read (without agents the counts line is the standard one). Plus signs, texts and the text of the arrow have no place in the file. Not built: atom-to-atom maps, RXN V3000 and RD files out, a drawing with several steps.
