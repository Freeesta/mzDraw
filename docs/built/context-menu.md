# Context menu, model built (PR 1; the page is PR 2)

`Editor::context_menu(x, y)` (`crates/mzdraw/src/context.rs`) hit-tests, settles the selection as a click would (a thing inside a larger selection keeps it) and returns JSON `{target, items: [{id, label, key?, enabled, checked?, children?}], notice?}` for the five targets: `atom` (element list with `More...`, charge, label, data, annotation, copy, cut, delete, select connected), `bond` (single, double, triple, wedge, hash, wavy, reverse direction, delete), `selection` (cut, copy, paste, duplicate, rotate, flip, delete, Copy as molfile / SMILES / SVG / PNG), `object` (edit, delete) and `canvas` (paste, select all, add structure from text, undo, redo, fit, zoom, save image, clear all). Labels are short English texts; ids are stable (`atom.el.N`, `bond.o.2`, `edit.copy`, ...) and carry the i18n lookup `draw2.ctx.<id>` for the page; `key` is the key the page binds to the same function, as a hint: Ctrl+Z / Y / A / D and Del are the keys of the item's action; Ctrl+C / X / V are clipboard events of the page (the item copies or cuts and answers `clipboard`, the page mirrors it); 1-3, W, Shift+W, Y, + / - and the element letters only pick a tool or act on the focused atom, so the item applies the same choice at once to what is under the pointer. On an empty document the canvas menu has no export item and carries `notice: "draw2.ctx.empty"`. `Editor::context_run(id)` runs one item through the existing commands (an `Op` of the `draw_edit/1` log, the clipboard, the selection, the view): one undo step, exact undo. What the editor cannot finish alone answers with the flag `ASK` (128) and `context_ask()` says what the page does (`element:<atom>`, `label:<atom>`, `data:<atom>`, `annotation:<atom>`, `text:<object>`, `import`, `fit`, `save-image`, `clipboard`, `copy-as:<kind>`; the text of Copy as comes from `context_copy_as`, the PNG plan from `context_png_plan`). A menu remembers a fingerprint of the document, selection, clipboard and view and refuses an item run after any of them changed (`error.draw2.contextStale`), so a stale menu cannot act on an old target; the view is part of the fingerprint, so a pan or a zoom between opening and running closes the menu too. A coordinate that is not finite is taken as 0 at the entry point, and `Editor::zoom` ignores a point or factor that is not finite. The charge items are disabled at the limit of +-4. Cut, copy and duplicate are disabled on a selection of bonds alone (nothing to copy). The headless door gained `out: "context:<x>,<y>"` (the menu of a right-click on the default view), the golden file has seven `contexts`, and `tests/parity.mjs` holds wasm == native on them. Wasm exports: `context_menu`, `context_run`, `context_close`, `context_ask`, `context_copy_as`, `context_png_plan`, `context_png_finish`. The default format of the saved image is not a setting yet (the page chooses, PNG).
