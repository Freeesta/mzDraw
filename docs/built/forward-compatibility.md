# Forward compatibility, built

the version rule for both formats — this version reads `mzdraw/1` and `mzdraw-settings/1`; a higher number is the file of a newer mzDraw and is refused with a key of its own (`error.draw2.documentNewer`, `error.draw2.styleNewer`), never half read; a format change that an older reader could not survive bumps the number. Within a version, a settings file keeps the keys this version does not know (next to `format` and `style`, and inside `style`) and writes them back unchanged in alphabetical order (`Style::unknown`). The same holds for a **document**: fields this version does not know, on the document, an atom, a bond or an object (`More`, kept as JSON text), are kept by `Document::from_json`, stay on their thing through edits and undo, and are written back by `Document::to_json` after the known fields, by key. The document is now written by hand, as it is read. They are kept when a drawing is opened in place (`Editor::open`, the autosave restore); adding a file to a drawing, pasting and copying go through the operations, which carry the known fields only.
