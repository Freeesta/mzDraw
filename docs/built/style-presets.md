# Style and presets, built

the settings file `mzdraw-settings/1` holds the drawing style in points (`crates/mzdraw/src/settings.rs`: bond length, line width, wedge width, hash spacing, double-bond spacing, label margin, font size, subscript scale, colour `element` or `mono`; every field optional, `preset` names the preset the others start from). Presets `mzlab` (default), `acs-1996`, `slides`; no RSC, Wiley or other journal preset until its numbers are read from the journal's guidelines. The style drives the screen and the SVG; the SVG is written in points, so it prints at the true size of the style. With this the default label size in files went from 14 to 12 (the file used 0.47 of the bond and the screen 0.4; one style now serves both and the screen kept its look), so SVG files saved before differ in size and label size from files saved now. It is not part of the document and is no undo step. The replay request takes `"style"` (a preset name or a settings object), so the CLI route gives the same bytes. Not built of the settings study: templates, abbreviations, shortcuts and editor sections (a file that has them keeps them, see the section "Forward compatibility" of this folder). The chosen style is remembered between visits: the page keeps the settings file the module writes (`style()`) in the browser (OPFS, `mzdraw-settings.json`) and gives it back to the module at the start; a file the module refuses is ignored.
