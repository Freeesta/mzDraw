# Keyboard editing and the outline, built

one atom has the keyboard focus (two rings on the canvas, `Overlay::focus`). Arrow keys walk along the bonds (the neighbour most in that direction), `Home` the first atom, `Page Down` / `Page Up` the next or previous structure, `Enter` / `Shift+Enter` grow a single or double bond (on an empty canvas `Enter` places a carbon), a letter sets the element of the focused atom, `1` `2` `3` the order of the bond just walked, `+` `-` the charge, `Space` selects the focused atom, `Delete` removes it, `Escape` leaves the focus. `Tab` is never taken: the study's "Tab = next piece" would trap the keyboard in the canvas (WCAG 2.1.2), so the pieces are on Page Down / Page Up. The page says where the focus is in the live line and shows "What is drawn": one line per structure with its Hill formula (`crates/mzdraw/src/outline.rs`, counted on the record, so abbreviations count as their atoms), tied to the canvas with `aria-describedby`. A closed help lists the keys. Not built: focus on a bond or an object, keyboard placing of arrows and texts, rebinding keys, a test with a real screen reader.
