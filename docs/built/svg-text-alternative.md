# Saved SVG with a text alternative, built

(arch-std-04): the root of the SVG the editor saves has `role="img"`, `aria-labelledby="t-<id> d-<id>"` and `xml:lang="en"`, and its first children are `<title>` (the outline line: the Hill formulas of the structures joined by "and", then "with a reaction arrow" if there is an arrow; "Empty drawing" for an empty document) and `<desc>` (one sentence: "Reaction scheme: C2H6O and CH4, with a reaction arrow." or, without an arrow, `C2H6O (level 2b) and C3H6O.`, the level shown when annotated); the ids of the two elements are `t-<id>` and `d-<id>`, with `<id>` 8 hex digits of a hash of the text and the document, so several saved SVGs inlined in one page do not collide; text is escaped and characters XML 1.0 forbids are written as blanks (in the carried JSON as `\uXXXX`). The text is made in Rust by `outline::alternative` from the same pieces as the outline list of the page; the English words come from a small fixed table there, because the file has no i18n layer. The picture itself and the carried document are unchanged (the `metadata` element comes right after the root tag, before the title). A test checks every golden SVG for SVG 1.1 elements and attributes only (`tests/svg_access.rs`). The CLI route gives the same bytes (replay request, `tests/parity.mjs`). Not built: a language other than English in the file, PNG text chunks. All 12 golden SVGs of the golden log (then one file, now the files of `tests/data/log/`) moved, each by the new root attributes and the two elements and nothing else.
