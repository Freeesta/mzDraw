# Stereo guard, built

(plan-21; `crates/mzdraw/src/stereo_guard.rs`, hooks in `editor.rs` (`run`, `say_stereo`) and `editor_nudge.rs`; `outcome.rs` arm `stereo`; section "Replay result" of docs/mzdraw.md.) In mzDraw the wedges are the drawing and the configuration is derived at export, so moving, turning or mirroring atoms can change a configuration with no stereo edit.

- `stereo_guard::signature(&Document, &[Piece]) -> Vec<(Piece, String)>`: for each asked piece (the ascending ids of a connected set of atoms; `pieces(doc)` lists them) that holds a wedge, the canonical isomeric SMILES (`Mol::canonical` of the record `mzlab-mol` reads from the wedges as drawn, the path of `save("smiles")`). A piece with no wedge is left out. Canonical, so the mirror image of a meso compound has the same signature as the compound.
- Live line: after a step whose operations are only `move`, `rotate` and `flip` (the editor's `run` and the key nudges), the signatures of the touched pieces that hold a wedge are compared before and after; a change is said as `draw2.say.stereoChanged` ("Configuration changed at atoms {what}.", the centres, i.e. the narrow ends of the wedges of the changed pieces). Report only: the step stands, an undo reverts it. Nothing is computed for a step with no wedge in the touched pieces, and never while a drag is under way (the drag is one `move` at the release; the test `stereo_guard_drag.rs` counts the signatures). `atoms.xy` is not an operation of this version, so it is not covered.
- Request arm `{"stereo":"kept"}` (row `expect stereo` of `schema::REQUEST`; the golden cases are `tests/data/log/stereo-guard.json`, parity wasm == native): false when a piece that held a wedge after `import` and has the same atoms at the end has another signature; `detail` names the centres and both signatures. A piece whose atoms changed (an edit of the structure) is not compared: its SMILES changes legitimately.
- Budget: 100-atom piece with 10 wedges, release build, median of 20, `cargo run --release -p mzdraw --example stereo_bench`: 0.306 ms (limit 1 ms; a test with a generous bound runs in the test build). Module size is printed by `tools/build_site.sh` (before and after in the PR).

Proof: unit tests and properties in `crates/mzdraw/tests/stereo_guard.rs` (plain flip flagged, rigid move and turn never, a neighbour dragged across the others, the arm; 1,000 random chiral documents with 5 geometry edits each: every plain flip flagged, no rigid edit flagged). Independent: `tools/fidelity/stereo.py` (RDKit, fetched at run time) compares our verdict with the change of the InChI stereo layer of the molfile of the drawing, for the 36 stereo structures of `tests/data/fidelity/set.smi`, a flip and a drag of one neighbour of every wedged centre each: 72 of 72 agree (RDKit 2026.09.2, 2026-11-21, `tests/data/fidelity/stereo.json`; `stereo_guard.rs` replays the same edits and checks the file is current).

Not built / not proven: re-solving the wedge placement (IUPAC ST-1.1), atropisomers, allenes, enhanced-stereo groups; the guard compares the drawing's own reading, so a configuration that `mzlab-mol` cannot read from the wedges (an ambiguous drawing) has no signature; the 72 cases show the drag of a neighbour to the mirrored point only, not every possible drag; the `mzlab` side of the arm (`mzlab-cli mol draw` exit codes) is mzLab's.
