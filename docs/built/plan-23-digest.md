# Digest `digest/1`, built

(plan-23; `crates/mzdraw/src/digest.rs`; section "Digest" of docs/mzdraw.md; one row in the `request` section of the table, `schema::REQUEST`.) `"out":"digest"` answers a few hundred bytes for an agent that cannot see the drawing, keys in a fixed order, numbers through `mzlab_mol::fixed`, written by hand: per connected structure, left to right, `ids` (atom ids as ranges), `formula` (Hill, the formula of the outline line with the ASCII minus), `box` (x0, y0, x1, y1, bond lengths, one decimal, label ink included), `labels` (`[id,text]` of every atom that is not a plain carbon and every abbreviation or R group), `stereo` (`[bond,"wedge"|"hash"|"wavy",narrow-end atom]`), `rings`; then `objects` (`[id,kind,box]`), `clearance` (the smallest gap between two structure boxes; `null` with fewer than two) and `std` (counts of `std/1` findings by key). No `draw_edit/1` op, no new exit code: with `report` or `expect` the digest is the `out` of a `draw-result/1` (a false expectation is exit 1 with the document on stdout). The CLI twin is `{"import":...,"log":[...],"out":"digest"}`; the page's `Editor::save("digest")` is the same function, so the bytes are the same (test `the_page_and_the_replay_route_...`, golden cases `tests/data/log/digest.json`, parity wasm == native in `tests/parity.mjs`).

Caps: 200 structures and 200 objects are listed and the rest counted in a last key `more` (`[structures, objects]`, present only then); the `clearance` runs over the structures listed; `std` is `null` ("not counted", not `{}` "none") above 1000 atoms because the `std/1` check rescans the drawing for every atom. One linear pass over atoms and bonds (union-find); `layout::pieces` and `route::Structures` are not used here because their piece search is quadratic.

Tests (`crates/mzdraw/tests/digest.rs`): the digest of a fixed synthetic document is byte-identical to `tests/data/digest/golden.txt` and to a second run; at most 1,200 bytes for a 30-atom structure with one arrow and one text; a 200-atom structure lists every hetero atom id; every id of the digest exists in the document (300 random drawings) and the ranges cover every atom once; the formulas equal those of the outline line; the box equals the extent of the `<line>` elements of the SVG of a structure without labels (read as the SVG states them, in points, at the bond length of the style); the counts of `std` equal those of `out: std`; caps; scaling (20,000 against 40,000 structures: at most 3 times the time, and a bound) and a bound for a 10,000-atom chain. The scaling test was tried against a quadratic mutation (a pairwise pass over the structures): it does not finish within two minutes where the real code takes 0.15 s. Runner: `tests/agent_suite.rs` runs the arm `digest` with a script as the model (the digest request is one call, its answer is added to the next prompt, its bytes count in the bytes of the run).

Independent proof: `tools/digest/ref.py` (RDKit, fetched at run time in a throw-away virtual environment, never committed) reads OUR digest of each of the 200 synthetic structures of `tests/data/fidelity/set.smi` and compares each formula with RDKit's `CalcMolFormula` of the same SMILES: 200 of 200 agree (RDKit 2026.09.2, 2026-11-21; reference output `tests/data/digest/rdkit-formulas.txt`). An R group is compared by element counts (RDKit reads `*`). It shows the formulas agree on this set; it does not show the boxes, ids or labels, nor formulas of drawings with abbreviations (RDKit has no such atom). The box test above is independent only for the geometry of the atoms: the ink of a label comes from the same `scene::label_extent` that the layout uses, and no program other than ours measures it.

Not built: the arm `digest` of plan-19 has its text (`tools/agent-suite/arms/digest.md`) and a turn loop in `tools/agent-suite/run.py` (up to 8 calls of the model command per run), but no model has been run: the kill test (`report+digest` against `report`, 15 points of pass@1 on the "surgical edits" and "several structures" tasks, median bytes) is the owner's run outside CI, and its result belongs in `docs/agent-suite/`; the arm stays unproven until then.
