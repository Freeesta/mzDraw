# Velocity benchmark `velocity/1`, built (tests and tools only; no editor change)

12 fixed synthetic tasks (`tests/data/velocity/tasks.json`: benzene, ethanol, isobutanol, ibuprofen, caffeine, anthracene, gonane, (2R,3R)-butane-2,3-diol with wedges, glycine zwitterion, a Boc amine, a two-component esterification with arrow and condition text, three structures in a row), each with the shortest hand-written page path known (`mzdraw.json`: tool, click, drag, key, type, focus; mouse, plus touch variants of benzene, ethanol and anthracene and a keyboard-only ethanol) and the `draw_edit/1` patch that draws it (`agent.json`). `node tests/velocity.mjs > velocity.json` plays the paths in Chromium, counts the actions and times each path up to the first step after which the drawing is the target (the identity of `mzlab-mol` `Mol::can`, so atom order and Kekule form do not matter, stereo does; the example `crates/mzdraw/examples/canon.rs` writes it); it replays every patch natively (`"agent"`: ops, bytes, median of 20 runs of the `replay` example, process start included). `--check` is the regression guard against `baseline.json` (actions only), `--guard-test` tests the guard with a doctored baseline. `crates/mzdraw/tests/velocity_tasks.rs` reads the targets with `mzlab-mol` and replays every patch natively. `tools/velocity/ketcher.mjs` fetches a pinned standalone Ketcher at run time (v3.21.0, sha256 checked, nothing committed) and plays `ketcher.json`; **not built**: the Ketcher paths are not written (the authoring session could not run the downloaded page), so no Ketcher number exists yet; `tools/velocity/check_targets.py` (RDKit second check of the targets: it parses the 12 targets and gives CIP labels, it measures no speed) was run by the owner with RDKit 2026.09.2 on macOS arm64, Python 3.14: all 12 parse and the butanediol target is (R,R) (`tests/data/velocity/targets_rdkit.txt`); `docs/plan/velocity-protocol.md` is the protocol for a person timing a desktop editor. The keyboard-only path starts with a counted `focus` step: the canvas comes after 36 Tab stops of the toolbar.
