# Light and dark tokens, built (PR 3 of the UI work)

every colour of the page comes from the `--mzd-*` tokens of `web/mzdraw.css` (prefix `NAMES.tokens`): a light and a dark set, chosen by `prefers-color-scheme` or by `data-theme="light|dark"` on the root, so a host maps its theme onto the tokens; the canvas is painted again when either changes. Warm neutral surfaces, ink that is never pure black or white, no yellow field. The e2e step "theme" measures WCAG 2.2 AA in both themes (text 4.5:1, icons, control borders and the focus ring 3:1), keeps the element colours at least ΔE 20 (CIE76) apart, and checks the focus ring. The golden SVGs are unchanged: the tokens colour the page, not the saved files.
