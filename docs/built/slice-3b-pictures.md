# Slice 3b, built (pictures that open again)

the SVG the editor saves carries its document (`mzdraw/1` as the text of a `metadata` element with the id `mzdraw`, `svg::carrying`; the picture itself is unchanged) and a new **PNG** does too (`png::finish`: an `iTXt` chunk with the keyword `mzdraw`, and `pHYs` so that the file prints at the size of its style). The pixels are made where a rasteriser is: the page draws the SVG of the module on a canvas of the size the module asks for (`png::plan`: 300 pixels per inch on white, fewer above 8192 pixels) and hands the bytes back. Opening either file (Open a file, or pasting the SVG) adds the drawing it carries, unknown fields included; a picture of another program is refused in words (`error.draw2.svgPlain`, `error.draw2.pngPlain`); the PNG reader checks every chunk length and the CRC of the document. The CLI route gets the SVG as before and can finish any PNG with `png::finish`; it has no rasteriser of its own.
