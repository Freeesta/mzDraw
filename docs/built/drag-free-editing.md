# Drag-free editing (arch-std-05), built

what a drag does is also possible with single actions or keys (WCAG 2.2 SC 2.5.7). With a selection and the canvas focused: `Alt+Arrow` moves it by 0.1 bond length, `Alt+Shift+Arrow` by 1, `Alt+[` / `Alt+]` turn it by 15° (about the mean of the atom positions, so 24 presses come back to the start within the 4 decimals of the document); each press is one `move` or `rotate` op in the log (no new operation), and presses of the same kind on the same selection within 1 s (time from the event stamp, no clock in Rust) are one undo step (`Session::run_into_last`). `Shift+Arrow` also adds the atom the focus walks to, and the bond between, to the selection. "Move here" (a `<button aria-pressed>` and key `M`, brings the select tool): a click or tap on an empty spot moves the selection so that its bounding-box centre lands there, one `move` op. The live line says each step (`draw2.announce.moved`, `draw2.announce.rotated`). The wasm `key` takes the event time stamp and Alt is bit 8 of `mods`. Not built: band selection by keys, focus on bonds and objects; on macOS `Option+[` types another character, so the turn keys work there only where the browser reports `[` / `]`.
