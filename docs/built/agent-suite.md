# Agent task suite `agent-suite/1`, built (plan-19; tests and tools only, no editor change)

30 fixed synthetic tasks in `tests/data/agent-suite/tasks.json` (`agent-suite-tasks/1`: 10 `build`, 10 `edit`, 10 `several`), one hand-written reference replay request each in `tests/data/agent-suite/ref/`, and a checker in Rust: `crates/mzdraw/tests/suite/check.rs`, shared by the example `crates/mzdraw/examples/suite_check.rs` (`suite_check TASK.json REQUEST.json`, one JSON line, exit 0 pass / 1 fail / 2 unreadable input) and the test `crates/mzdraw/tests/agent_suite.rs` through `#[path]`, so the library and the wasm module carry no suite code. A check is: the canonical SMILES (`mzlab-mol` `Mol::can`) of each connected piece of the final drawing, left to right when `order` is set; the arrows, plus signs and texts (kind, text, place between or after pieces); for edits, the `edit_zone` (everything of the start document outside it keeps id, element, position and the whole atom, bond and object); `std` none or `std_absent`. The checker forces `out` to `mzdraw` and drops `report`, `dry_run` and `expect` before it replays the request. Tests: every reference passes; a broken copy of each (one atom turned into silicon) fails; a swap of two elements (same formula, other structure) fails; a moved untouched atom and a drawing rebuilt from the target SMILES fail an edit; the report line is the same bytes twice; the runner exits 2 with a stable key (`arm_unknown:`, `arm_duplicate:`, `arm_text_missing:`) and prints an arm as a sorted set (`--parse-arm-only`), tested from Rust, skipped with a message when python3 is absent.

`tools/agent-suite/run.py --model-cmd 'CMD' --arm plain --runs 1` writes `agent-suite/1` on stdout (keys in a fixed order; per task the runs with pass, calls, request bytes, tokens and reason; overall pass@1 with the Wilson 95% interval, median calls, median bytes); `--reference` runs the reference solutions as the model (30 of 30). `--arm` is `plain` or a `+`-joined, sorted set of `report`, `digest`, `select`, `plan`, `grant`; the text of a feature is `tools/agent-suite/arms/<name>.md`. `tools/agent-suite/ref.py` is the independent check: RDKit 2026.09.2 (`pip install rdkit` in a throw-away virtual environment outside the repository, nothing committed) reads the SMILES of every reference solution and every target and compares InChIKeys: 30 of 30 agree; the keys of the targets are in `tests/data/agent-suite/inchikeys.txt` with the RDKit version and the date.

Not built: no model has been run (the owner runs external models outside CI; `docs/agent-suite/` holds no result yet); only `plain` and `report` have an arm text: `digest`, `select`, `plan` and `grant` are known names that exit 2 until the slice that builds the feature writes its `arms/<name>.md`; the adversarial set of plan-28 (`tests/data/agent-suite/adversarial.json`); no baseline on RDKit's or Ketcher's API. The request is judged on its final drawing only: a request that fails midway is a failed run, the tokens of a model are whatever CMD reports.
