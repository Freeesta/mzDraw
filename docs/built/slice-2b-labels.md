# Slice 2b, built

atom labels (`lab` of an atom, `atom.set.lab` in the log; the empty text or a new element takes it away). An abbreviation of the table `crates/mzdraw/src/label.rs` (31 groups: Me, Et, Ph, Boc, NO2, CO2H, ...) is drawn as its name with lowered digits and expanded to its atoms in the record and the molfile (the expansion atoms follow the pool, with placeholder positions next to the label that can overlap the drawing). An R group (`R`, `R1` ... `R32`) is an `R#` atom with `M  RGP` in the molfile and the query atom `A` for the check; `mzlab-mol` refuses R groups, so a molfile with them cannot be imported yet and the `mol/1` record holds a helium stand-in. Label tool `label:<name>`, a field with the list in the toolbar, key `L`. The operations of the log are read by a hand-written reader (`Op::from_value`) instead of the derived one, which took 45 kB off the module (474,490 B; the cap stays 512,000 B, a raise is the owner's decision).
