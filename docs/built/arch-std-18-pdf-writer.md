# arch-std-18, built (PDF out: vector, text as text, the document attached)

`crates/mzdraw/src/pdf.rs` writes the PDF 1.7 of a drawing from the same display list as the SVG (`svg::laid_out`): one page of the drawing's size in points, white ground, lines and filled polygons as path operators (round caps), text as text in the base-14 font Helvetica with WinAnsi encoding (a character the encoding lacks is written `?`; the minus sign as an en dash), element colours as RGB, text widths from the table the SVG uses. Streams are stored (no compressor), the cross-reference table has exact offsets, there is no date, and `/ID` is a hash of the content, so the same drawing gives the same bytes.

The document (`mzdraw/1`, `mzdraw.json`) and its V3000 molfile (`mzdraw.mol`) are embedded files of the name tree `/EmbeddedFiles`. `pdf::carried` reads a PDF back through the cross-reference table (every offset and length checked, a damaged or hostile file is refused, never a panic) and `io::import_bytes` opens it; a PDF of another program has no `mzdraw.json` and is refused in words (`error.draw2.pdfPlain`).

Routes: the page has **PDF** in the export list (`save_pdf()`), also by keyboard and by touch. CLI: request `{"out":"pdf"}` gives the file as base64 (`Editor::save("pdf")`; the `--raw` of `mol draw` writes the bytes); the golden cases are in the `pdf` section of `tests/data/log/pdf.json`, held equal on wasm and native by `tests/parity.mjs`. `tools/check_pdf.sh` runs `qpdf --check`, `pdfinfo`, `pdfdetach` and `pdftotext` on those cases (a missing program is said, not passed). `"out":"pdf"` is a request output, not an operation of `draw_edit/1`: no operation was added and the table of `schema.rs` is unchanged.

Not built: embedded TrueType fonts, PDF/A, reading PDFs of other programs, several pages, characters outside WinAnsi (Greek letters and the like appear as `?`), compressed streams, PDF 2.0 `/AF` (associated files). Chromium's PDF viewer is not in headless Chromium, so the viewer check is not made there; poppler and qpdf are the independent readers.
