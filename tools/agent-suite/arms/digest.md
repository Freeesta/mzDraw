# Arm: digest

A request with `"out":"digest"` answers with `digest/1`, a few hundred bytes that say where things are in the drawing your request builds (start it from the same `import` and `log`; it starts again from `import`, like any request). Ask for it when you need an id or a place and do not want to read the whole `mzdraw/1` document: it is one more call, its answer counts in the bytes of your run, and you may ask as often as you like (an answer is given to you, then you send the next request; the request you send last is the answer that is judged, so end with the drawing, not with a digest).

Keys, in this order: `pieces` (one per connected structure, left to right): `ids` (atom ids as ranges, `"1-12,15"`), `formula` (Hill), `box` (`[x0,y0,x1,y1]` in bond lengths, one decimal, y up, label ink included), `labels` (`[[atom id,"N"],...]` for every atom that is not a plain carbon and every abbreviation), `stereo` (`[[bond id,"wedge"|"hash"|"wavy",narrow-end atom id],...]`), `rings`; `objects` (`[[id,kind,box],...]` for arrows, plus signs and texts); `clearance` (the smallest gap between two structure boxes, bond lengths, `null` with fewer than two); `std` (the number of `std/1` findings per key). The digest names no CIP label and shows no picture.
